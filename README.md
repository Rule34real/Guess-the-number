# Guess-the-number
Guess the number.
By guessing the number you guess the number. The guessed number is either right or wrong. If the guessed number is wonrg you have a few more tries to guess the right number.

In this project you have to guess the given number. If you guess the number you win but if you fail to guess it you lose.
